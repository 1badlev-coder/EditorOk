# Editor-Ok — нативное Android-приложение

Полноценное приложение (не TWA/WebView), пакет `site.kentok.lists`.

Проект: `D:\APP\editor-ok_android-app`

## Возможности (v2.1)

1. Нативный редактор многоуровневых списков
2. Синхронизация документов с https://editor-ok.kent-ok.site/
3. При конфликте ревизий — «Заменить» или «Сохранить под другим именем»
4. Офлайн-режим; при отсутствии сети проверка связи каждые 5 секунд
5. Красный баннер: данные сохраняются на устройстве
6. При запуске и появлении сети — копия документов сервер ↔ устройство
7. Файлы на устройстве в AES-256-GCM; ключ = PBKDF2(логин + пароль)
8. Оформление строк (жирный/курсив/подчёркивание/зачёркивание, шрифт, размер, цвет)
9. Свайп по номеру строки — уровень вложенности
10. Фото в строках (галерея → upload / локально офлайн)
11. Экран «Вид» — плитки документов
12. ПИН-вход (если включён на сайте)
13. Выгрузка документа в Word (.docx)

Ещё нет полного паритета с сайтом: фото, «Вид», Word, ПИН, оформление строки, свайпы — можно нарастить следующим этапом.

## Сборка

1. Откройте `D:\APP\editor-ok_android-app` в Android Studio (Ladybug+ / SDK 35 / JDK 21)
2. Sync Gradle (`local-m2` → зеркало mpult-app + Huawei)
3. Run или Build → Build APK(s)
4. APK: `app\build\outputs\apk\debug\app-debug.apk`  
   Тот же `applicationId`, что у старого TWA — заменяет его при установке

Нужен интернет для **первого** входа. Дальше документы доступны офлайн.

## Сервер

Нужен установщик `update_19` на сайте: API `mobile_login` и поле `rev` в `api=list`.
